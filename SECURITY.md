# Security Policy

## Supported Versions

Knoodle is currently in beta. Security updates are provided for the latest available beta version where reasonably possible.

| Version | Supported |
| ------- | --------- |
| Beta (latest) | Yes |
| Older beta versions | No guarantee |
| Unreleased development versions | No guarantee |

Users are encouraged to use the latest available version of Knoodle to benefit from the most recent fixes and improvements.

## Reporting a Vulnerability

If you discover a potential security vulnerability in Knoodle, please report it responsibly.

**Contact:** kaier.chang@proton.me

Please include the following information in your report where possible:

- A clear description of the vulnerability.
- The steps required to reproduce the issue.
- The potential impact.
- Screenshots, logs, or other relevant evidence, if available.

Please do not include passwords, access tokens, private user data, or other sensitive information in your report.

### What Happens Next?

- **Acknowledgment:** You can expect an initial response within 7 days.
- **Assessment:** The report will be reviewed to determine its validity, severity, and potential impact.
- **Updates:** If the vulnerability is confirmed, you will receive updates as the investigation progresses.
- **Resolution:** Confirmed vulnerabilities will be prioritized based on severity and addressed where reasonably possible.
- **Declined reports:** If the issue cannot be reproduced, is outside the scope of Knoodle, or is not considered a security vulnerability, an explanation will be provided where possible.

Please note that response and resolution times may vary depending on the complexity and severity of the report.

## Responsible Disclosure

Please allow reasonable time for a vulnerability to be investigated and addressed before publicly disclosing it.

Do not exploit vulnerabilities to access other users' accounts or data, modify or delete information, disrupt the service, or compromise systems beyond what is necessary to demonstrate the issue.

Please report vulnerabilities privately rather than opening a public GitHub issue.

## Scope

This policy covers security vulnerabilities affecting Knoodle, including its website, authentication, account handling, and application functionality.

Third-party services may have their own security reporting procedures. Vulnerabilities affecting those services should also be reported to their respective providers.

## Important Notice

Knoodle is an actively developed beta project. Although reasonable efforts are made to improve its security, no software can be guaranteed to be completely free of vulnerabilities.

Thank you for helping keep Knoodle and its users safe.
